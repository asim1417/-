# التكلفة والوقت والمخاطر وخارطة الطريق

## خطة MVP (8 أسابيع)
| الأسبوع | المخرجات |
|---|---|
| 1 | تحليل السوق، الاسم والهوية، تحديد المصادر، تصميم قاعدة البيانات (منجز في هذا المستودع). |
| 2 | UX/UI، الواجهات الأساسية، التسجيل ولوحة الطالب. |
| 3 | مسار Medical Terminology + General Anatomy + أول 30 درسًا. |
| 4 | بنك 500 سؤال أولي، نظام flashcards، تتبّع التقدّم. |
| 5 | مساعد RAG، ربط المصادر، نظام الاستشهادات. |
| 6 | لوحة الإدارة، مراجعة المحتوى، الاشتراكات. |
| 7 | ضبط الجودة، تجربة 50 طالبًا، تحسين الجوال. |
| 8 | إطلاق تجريبي + حملة تسويقية + نظام إحالة. |

## تقدير التكلفة الشهرية (تشغيل MVP)
| البند | تقدير |
|---|---|
| استضافة (Vercel Pro) | ~20$ |
| قاعدة بيانات مُدارة (Neon/Supabase pg+pgvector) | 0–25$ |
| نموذج المرشد (Anthropic) | متغيّر بالاستخدام؛ استخدم Haiku للأسئلة الروتينية وSonnet للشرح العميق |
| تضمينات (Voyage) اختياري | متغيّر |
| المجموع البنية التحتية | ~50–100$/شهر في البداية |
**أكبر تكلفة حقيقية = إنتاج المحتوى الطبي المُراجَع، لا البنية التقنية.**

## المخاطر وعلاجها
| الخطر | العلاج |
|---|---|
| دقة المحتوى الطبي | مراجعة علمية إلزامية (Reviewer role) قبل النشر + استشهاد لكل درس. |
| تجاوز حدود السلامة (تشخيص) | حارس `safety.ts` + system prompt صارم + سجل تدقيق لكل إجابة. |
| تراخيص المصادر | OpenStax (CC BY) بالإحالة، MedlinePlus/PubMed (نطاق عام)؛ لا نسخ محمي. |
| «هلوسة» النموذج | RAG يلزم الإجابة من سياق المصادر؛ وإلا يصرّح بعدم الكفاية. |
| ثبات الطلب (retention) | التكرار الذكي + الشارات + تحدي 30 يومًا. |
| تكلفة النموذج | توجيه متعدد المزوّدين وتخزين مؤقت للأسئلة المتكررة. |

## خارطة طريق سنة
- **ربع 1:** إتمام 17 مسارًا، 300+ درسًا، 3000 سؤال مُراجَع، تطبيق جوال (PWA ثم native).
- **ربع 2:** تحليلات الضعف الفردي، خطط مراجعة تكيّفية، وضع OSPE بالصور.
- **ربع 3:** تكامل الجامعات (SSO + تقارير)، لوحة أعضاء هيئة تدريس.
- **ربع 4:** توسّع خليجي كامل، محتوى SAQ/الحالات، شراكات كليات الطب.

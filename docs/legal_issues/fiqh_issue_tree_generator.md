# مولّد شجرة المسائل الفقهية — Fiqh Issue Tree Generator

أداة تحصر **المسائل الفقهية من كتاب البيع حتى نهاية الموسوعة** (المعاملات فما
بعدها)، استنادًا إلى بنية **الموسوعة الفقهية الكويتية** والمتون الفقهية المعتمدة،
وتنتج **شجرة مسائل (≥ 3000 مسألة)** جاهزة كقاعدة بيانات أولية، مع **مواءمة سعودية
مبدئية** تربط كل مسألة بالنظام السعودي المقابل.

> ⚠️ بذرة هيكلية فقهية (`fiqh_seed`) للحصر والتبويب فقط. كل مسألة تحمل
> `needs_human_review = true` وتحتاج **مراجعة صياغة سعودية** وربطًا دقيقًا
> بالأنظمة قبل الاعتماد. ليست فتوى ولا نظامًا سعوديًا معتمدًا.

## المنهج (كما طُلب)
1. **الحصر**: من كتاب البيع إلى نهاية الموسوعة (تجاوز العبادات، لأن المعاملات هي
   ما يقابل الأنظمة).
2. **التوليد التركيبي البرمجي**: `قسم > كتاب > باب > مسألة`، بتطبيق أبعاد المسألة
   (تعريف، حكم، أركان، شروط، أنواع، صور، موانع، آثار، ضمان، خيار/فسخ، نزاع وإثبات،
   تكييف نظامي، تطبيقات معاصرة، خلاف فقهي) على كل باب — مع حذف الأبعاد غير المناسبة
   للأقسام غير المالية وتفادي التكرار.
3. **الربط بالأنظمة السعودية**: حقل `suggested_saudi_nizam` لكل مسألة.
4. **المراجعة البشرية**: تُراجَع الصياغة سعوديًا ويُحكم الربط قبل الاعتماد.

## التشغيل
```bash
python scripts/legal_issues/fiqh_issue_tree_generator.py
```
يعتمد فقط على المكتبة القياسية + دالة `normalize_arabic` من مستخرج الموسوعة المصرية.

## البنية (5 مستويات)
- **L0**: الموسوعة (من البيع إلى النهاية)
- **L1**: القسم الكبير — المعاملات المالية · الأحوال الشخصية والأسرة · المواريث
  والوصايا · الجنايات والحدود · القضاء والإثبات والأيمان
- **L2**: الكتاب الفقهي (البيع، الإجارة، النكاح، الجنايات، القضاء...)
- **L3**: الباب
- **L4**: المسألة الفقهية ← هذه هي وحدة العدّ (≥ 3000)

## الربط بالأنظمة السعودية (المادة النظامية)
كل عقدة تحمل أربعة حقول للمواءمة النظامية:
- `suggested_saudi_nizam` — النظام السعودي المقابل.
- `suggested_saudi_nizam_chapter` — الباب/العقد النظامي داخل النظام.
- `suggested_saudi_article_ref` — مرجع المادة (يُدرج النطاق المؤكَّد فقط؛ وإلا
  «يُحدَّد بالمراجعة» تفاديًا للتخمين).
- `saudi_nizam_url` — رابط النظام في المصدر الرسمي.

| الكتاب/القسم الفقهي | النظام والباب المقابل |
|---|---|
| البيع/القرض/الهبة/الصلح | نظام المعاملات المدنية — العقود الناقلة للملكية |
| الإجارة/الوكالة/الوديعة | نظام المعاملات المدنية — الإيجار / الواردة على العمل |
| الشركة/المضاربة | نظام الشركات / عقود المشاركات |
| الرهن/الكفالة/الحوالة | المعاملات المدنية — التأمينات/الكفالة/انتقال الالتزام |
| الإفلاس والحجر | نظام الإفلاس + الأهلية في المعاملات المدنية |
| النكاح/الطلاق/الحضانة/النفقة | نظام الأحوال الشخصية (الأبواب 1–4) |
| الوصايا/المواريث | نظام الأحوال الشخصية (البابان 6–7) |
| القضاء/الدعوى | نظام المرافعات الشرعية |
| الشهادة/اليمين/الإقرار/البينات | نظام الإثبات |
| الجنايات/الحدود/القصاص/الديات | أحكام شرعية + أنظمة جزائية (غير مقننة في نظام عقوبات عام) |

> خريطة الأنظمة وبنيتها وروابطها الرسمية موثّقة في
> `config/legal_issues/saudi_nizam_map.json` (النطاق المؤكَّد الوحيد حاليًا:
> عقد المقاولة م461–478). الحدود والقصاص مرجعيتها شرعية لا نص نظامي مرقّم.

## الخطوة التالية الموصى بها
1. مراجعة بشرية لصياغة المسائل سعوديًا (عمود `node_title`).
2. إحكام الربط في `suggested_saudi_nizam` + إضافة المادة النظامية المقابلة.
3. ربط الشجرة الفقهية بالشجرة المصرية (مستخرج الموسوعة المصرية) لإكمال المواءمة.

# قائمة الإطلاق (Go-Live)

## مُنجَز تقنيًا في هذا المستودع
- ✅ واجهات الطالب RTL بهوية MedKey Gulf (رئيسية، مسارات، مفاتيح، درس، أسئلة، مرشد) + أيقونات خطية + تذييل.
- ✅ قاعدة بيانات 27 جدولًا (Prisma + pgvector) وعلاقات متكاملة (تحقّق QA ناجح).
- ✅ بنك أسئلة مُحقّق (38) + مُدقّق آلي `npm run qa` + بوابة مراجعة علمية (/admin/review).
- ✅ صلاحيات RBAC خادمية: دخول (/login)، حراسة /admin، حماية POST المراجعة.
- ✅ لوحة تحكم (/admin): إحصاءات + استيعاب مصادر + مراجعة.
- ✅ امتثال تنظيمي (/legal): PDPL، الشروط، إخلاء المسؤولية الطبية، إتاحة WCAG 2.1 AA.
- ✅ ربط فعلي بالمصادر المفتوحة (MedlinePlus/PubMed/OpenStax) + استشهادات.

## يتطلّب مفاتيحك (لا يمكن أتمتته دوني بها)
1. **قاعدة بيانات إنتاج**: أنشئ Postgres+pgvector (Neon/Supabase) وضع `DATABASE_URL`.
2. **مفتاح Anthropic**: `ANTHROPIC_API_KEY` لتفعيل المرشد.
3. **أسرار المصادقة**: `AUTH_SECRET` عشوائي + `ADMIN_PASSCODE` قوي.
4. **GitHub**: ادفع عبر `deploy/push-to-github.sh` بتوكنك، ثم اربط المستودع بـ Vercel.

## خطوات الإطلاق النهائي
```bash
# 1) الأسرار في Vercel: DATABASE_URL, ANTHROPIC_API_KEY, AUTH_SECRET, ADMIN_PASSCODE
# 2) تهيئة القاعدة
npm run db:push && npm run db:seed && npm run ingest
# 3) اعتمِد الأسئلة من /admin/review (بوابة: لا يُعرض للطالب إلا المعتمد)
# 4) رقِّ النشر إلى production في Vercel
```
